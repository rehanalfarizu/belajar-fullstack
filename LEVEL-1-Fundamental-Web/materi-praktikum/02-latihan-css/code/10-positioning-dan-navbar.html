📌 Sticky Header — tetap di atas saat scroll dalam section ini

Scroll ke bawah untuk melihat sticky header tetap di atas. Saat section ini keluar dari viewport, sticky header akan ikut hilang (beda dengan fixed yang selalu terlihat).

Perbedaan Fixed vs Sticky:
- Fixed: Selalu relatif terhadap viewport — tidak pernah hilang saat scroll.
- Sticky: Relatif terhadap container/scroll — hilang saat container keluar viewport.
