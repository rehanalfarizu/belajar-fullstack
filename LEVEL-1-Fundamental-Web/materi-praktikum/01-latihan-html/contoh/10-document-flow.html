Block vs Inline Elements

Halaman ini mendemonstrasikan perbedaan antara block elements dan inline elements dalam HTML.

Block Elements

Block elements selalu dimulai di baris baru dan memakan lebar penuh dari parent container-nya.

Div adalah block element — saya mulai di baris baru
Div kedua — saya juga mulai di baris baru
Div ketiga

Contoh Block Elements:

Paragraf ini adalah block element.

Paragraf ini juga block element — masing-masing mulai di baris baru.

Unordered List (Block):

  • Item 1
  • Item 2
  • Item 3

Ordered List (Block):

  1. Langkah pertama
  2. Langkah kedua
  3. Langkah ketiga

Inline Elements

Inline elements tidak memulai baris baru dan hanya memakan lebar sesuai dengan kontennya.

Bold (strong) dan miring (em) dan disorot (mark) dan link (a) dan kecil (small)

Kode: console.log("Hello") dan Variabel: x dan Contoh keyboard: Ctrl + C

Inline vs Block: Perbandingan Langsung

DIV (block) — saya memakan seluruh lebar
SPAN (inline) — saya hanya sepertinya sebesar teks saya

Mengapa Ini Penting?

Memahami block dan inline sangat penting karena:

  • Layout CSS — display property (block, inline, flex, grid) mengatur cara elemen ditampilkan.
  • Box Model — margin dan padding berperilaku berbeda di block dan inline elements.
  • Semantic HTML — menggunakan tag yang tepat membuat halaman lebih accessible dan SEO-friendly.
