## Cara Pakai Tutorial

```
1. Ikuti tutorial URUT dari 01 → 06
2. Setiap tutorial ada bagian TEORI (belajar konsep)
3. Lalu bagian PRAKTIK (ketik kode, lihat hasilnya)
4. Akhiri dengan MINI-CHALLENGE (latihan soal)
```

## Tips Sebelum Memulai

```
1. Pastikan VSCode sudah terinstall (baca software/README.md)
2. Buat folder kerja: ~/belajar-web/
3. Buat subfolder: ~/belajar-web/level-1/
4. Ikuti setiap tutorial dari awal, jangan skip
5. Setiap ada kode, KETIK sendiri (jangan copy-paste)
```
