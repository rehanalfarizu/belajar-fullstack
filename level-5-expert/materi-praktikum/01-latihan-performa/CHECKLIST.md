# CHECKLIST — Performa Web

Centang dengan jujur. Angka tanpa bukti tidak dihitung.

---

## Pemahaman Konsep

- [ ] Aku bisa menjelaskan LCP, INP, dan CLS dengan bahasaku sendiri
- [ ] Aku paham beda data lab (Lighthouse) dan data lapangan (pengguna nyata)
- [ ] Aku tahu kenapa mengukur harus di build produksi
- [ ] Aku paham apa itu tree-shaking dan code splitting
- [ ] Aku paham kenapa gambar tanpa ukuran menyebabkan layout shift
- [ ] Aku bisa menjelaskan kenapa optimasi tanpa ukuran awal hanyalah tebakan

---

## Kemampuan Praktis

- [ ] Aku bisa menjalankan Lighthouse dan membaca laporannya
- [ ] Aku bisa menemukan elemen LCP lewat DevTools
- [ ] Aku bisa memvisualisasikan bundle dan menemukan paket terbesar
- [ ] Aku bisa memecah bundle dengan `React.lazy` dan konfigurasi Vite
- [ ] Aku bisa memakai tab Network, Performance, dan Coverage
- [ ] Aku bisa membuat gambar responsif dengan `srcset` dan lazy loading

---

## Kebiasaan Baik

- [ ] Satu perubahan per pengukuran, dengan catatan angka sebelum dan sesudah
- [ ] Aku mengulang pengukuran beberapa kali karena angkanya berfluktuasi
- [ ] Aku memeriksa dependency baru sebelum menambahkannya: ukurannya, dan
      apakah masih dirawat
      (baca [Konfigurasi Aman](../../../modul-keamanan-web/07-konfigurasi-aman/README.md))
- [ ] Aku tidak memuat script pihak ketiga dari sumber tidak jelas hanya demi
      kecepatan atau fitur
      (baca [XSS dan CSRF](../../../modul-keamanan-web/06-xss-dan-csrf/README.md))
- [ ] Aku mencatat optimasi yang tidak berhasil, bukan hanya yang berhasil
