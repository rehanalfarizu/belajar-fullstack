# CHECKLIST — Konfigurasi Aman

## Pemahaman Konsep

- [ ] Aku paham kenapa secret tidak boleh di-hardcode
- [ ] Aku paham cara kerja environment variables
- [ ] Aku tahu security headers yang penting
- [ ] Aku paham risiko dependency vulnerabilities

## Kemampuan Praktis

- [ ] Aku bisa setup .env dan .env.example
- [ ] Aku bisa menambahkan security headers
- [ ] Aku bisa menjalankan npm audit dan fix vulnerabilities
- [ ] Aku bisa membuat error handler yang aman

## Best Practices

- [ ] Secret SELALU di environment variables
- [ ] .env SELALU di .gitignore
- [ ] npm audit RUTIN dijalankan
- [ ] Error message TIDAK bocorkan internal info
- [ ] HTTPS digunakan di production
