# CHECKLIST — XSS dan CSRF

## Pemahaman Konsep

- [ ] Aku paham apa itu XSS dan 3 jenisnya
- [ ] Aku paham perbedaan innerHTML dan textContent
- [ ] Aku paham apa itu CSRF dan cara kerjanya
- [ ] Aku paham fungsi CSRF token

## Kemampuan Praktis

- [ ] Aku bisa mengidentifikasi kerentanan XSS
- [ ] Aku bisa sanitize user input untuk output
- [ ] Aku bisa implementasi CSRF token
- [ ] Aku bisa set SameSite cookie

## Best Practices

- [ ] Aku SELALU escape output dari user input
- [ ] Aku menggunakan textContent bukan innerHTML untuk text
- [ ] Aku set Content-Security-Policy header
- [ ] Aku implementasi CSRF protection untuk state-changing request
- [ ] Aku set cookie dengan SameSite=Strict
