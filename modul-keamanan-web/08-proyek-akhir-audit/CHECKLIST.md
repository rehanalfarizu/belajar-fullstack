# CHECKLIST — Proyek Akhir Audit

## Proses Audit

- [ ] Aplikasi dipilih dan bisa dijalankan
- [ ] Semua item checklist OWASP dicek
- [ ] Setiap temuan tercatat dengan detail
- [ ] Severity diberikan untuk setiap temuan

## Laporan

- [ ] Format laporan sesuai template
- [ ] Ada bukti (screenshot/code) untuk setiap temuan
- [ ] Rekomendasi perbaikan jelas
- [ ] Status fixed/pending tercatat

## Perbaikan

- [ ] Semua temuan Critical diperbaiki
- [ ] Semua temuan High diperbaiki
- [ ] Temuan Medium/Low diperbaiki atau ada justifikasi

## Portofolio

- [ ] README proyek di-update
- [ ] Ada bagian "Keamanan yang Diterapkan"
- [ ] Bisa menjelaskan setiap security measure

## Kesiapan Interview

- [ ] Bisa jelaskan proses audit
- [ ] Bisa jelaskan temuan utama
- [ ] Bisa jelaskan cara perbaikan
- [ ] Bisa jelaskan kenapa keamanan penting
