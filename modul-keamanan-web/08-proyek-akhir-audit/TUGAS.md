# TUGAS — Audit Aplikasi Sendiri

## Hasil Akhir

1. Laporan audit lengkap dengan temuan dan perbaikan
2. Aplikasi yang sudah diperbaiki
3. README portofolio dengan bagian keamanan

---

## Langkah 1: Pilih Aplikasi (30 menit)

1. Pilih aplikasi yang akan diaudit
2. Pastikan bisa running di local
3. Tulis informasi dasar di laporan

---

## Langkah 2: Audit dengan Checklist (2-3 jam)

1. Buka `README.md` dan ikuti checklist
2. Untuk setiap item, cek aplikasimu
3. Catat setiap temuan yang ditemukan
4. Beri severity: Critical / High / Medium / Low

---

## Langkah 3: Tulis Laporan (1 jam)

1. Buat file `kerjakan-di-sini/laporan-audit.md`
2. Ikuti format di README
3. Sertakan screenshot/code snippet sebagai bukti

---

## Langkah 4: Perbaiki Temuan (2-4 jam)

1. Perbaiki dari severity tertinggi
2. Update status di laporan
3. Test ulang setelah perbaikan

---

## Langkah 5: Update README Portofolio (30 menit)

1. Tambahkan bagian "Keamanan yang Diterapkan"
2. List semua security measure yang ada
3. Ini yang akan dilihat recruiter/interviewer

---

## File yang Perlu Diisi

```
kerjakan-di-sini/
└── laporan-audit.md     ← Laporan lengkap
```

## Verifikasi Final

- [ ] Semua item checklist sudah dicek
- [ ] Semua temuan tercatat di laporan
- [ ] Semua temuan critical/high sudah diperbaiki
- [ ] README portofolio sudah di-update
- [ ] Bisa menjelaskan keamanan yang diterapkan tanpa baca catatan
