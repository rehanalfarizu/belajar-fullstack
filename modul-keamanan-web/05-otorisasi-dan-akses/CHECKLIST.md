# CHECKLIST — Otorisasi dan Akses

## Pemahaman Konsep

- [ ] Aku paham perbedaan autentikasi dan otorisasi
- [ ] Aku paham apa itu IDOR dan kenapa berbahaya
- [ ] Aku paham prinsip least privilege
- [ ] Aku paham perbedaan RBAC dan ABAC

## Kemampuan Praktis

- [ ] Aku bisa mengidentifikasi endpoint yang rentan IDOR
- [ ] Aku bisa implementasi pengecekan kepemilikan resource
- [ ] Aku bisa membuat role-based middleware
- [ ] Aku bisa protect admin-only routes

## Best Practices

- [ ] Aku SELALU cek kepemilikan resource di server
- [ ] Aku tidak mengandalkan hidden UI untuk security
- [ ] Aku menggunakan prinsip default deny
- [ ] Aku membuat audit log untuk akses sensitif
