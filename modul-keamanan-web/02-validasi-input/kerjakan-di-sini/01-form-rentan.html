Tugasmu: bypass validasi ini menggunakan DevTools.

Instruksi Bypass:

  1. Buka DevTools (F12 atau klik kanan → Inspect)
  2. Pilih tab "Elements"

  4. Di panel kanan, hapus atribut required dan type="email"
  5. Isi form dengan data tidak valid
  6. Klik Daftar
  7. Perhatikan: data tidak valid tetap diterima!
