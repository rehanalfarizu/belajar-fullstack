## 📖 Materi Teori

Lima modul teori React:

1. **Modul 01 — React Fundamental**: JSX, Component, dan Props.
2. **Modul 02 — Hooks**: useState, useEffect, useRef, useCallback, dan useMemo.
3. **Modul 03 — React Router**: Routes, params, nested dan protected routes.
4. **Modul 04 — State Management**: Context, reducer, Zustand, dan server state.
5. **Modul 05 — Form**: controlled form, validation, dan accessibility.
6. **Modul 06 — Quality**: profiling, request race, bundle, XSS, session, dan
   dependency security.

## 🏋️ Praktikum

### React Dasar (01-latihan-react)

1. **Hello World** — Vite dan JSX.
2. **Component** — Function component dan Props.
3. **Conditional** — if/ternary, &&, dan ||.
4. **List & Keys** — map() dan key prop.
5. **Props Types** — Props dan default props.
6. **Events** — onClick dan onChange.
7. **State Counter** — useState.
8. **Multiple States** — useState dengan object.
9. **Pure Components** — React.memo.
10. **Component Composition** — children prop.

Lanjutkan ke hooks, router, state, dan form melalui README masing-masing.
