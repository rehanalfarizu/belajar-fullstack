# Contoh — Routing dan Controller

Ini solusi referensi. Jangan dibuka sebelum punya jawaban sendiri yang jalan.

Solusi di sini bukan satu-satunya jawaban benar. Kalau test kamu hijau dan
semua Syarat di soal terpenuhi, jawabanmu sah walaupun berbeda.

## Daftar File

| File | Untuk soal | Lokasi di `toko-latihan/` |
|---|---|---|
| `01-product-controller.php` | Soal 01 — Product Controller | `app/Http/Controllers/ProductController.php` |
| `02-routes-katalog.php` | Soal 02 — Route Group dan Nama | bawah `routes/web.php` (+ contoh test di komentar) |
| `03-middleware-jam-buka.php` | Soal 03 — Middleware Jam Buka | `app/Http/Middleware/PastikanTokoBuka.php` (+ `bootstrap/app.php`, route, dan test di komentar) |

## Cara Membandingkan

1. Jalankan test kamu dulu, catat hasilnya.
2. Baca solusi, cari **satu** hal yang berbeda dari jawabanmu.
3. Tanya ke diri sendiri: "Kenapa dia pilih cara itu? Apa ada kasus yang jawabanku lewatkan?"
4. Tutup file solusi, perbaiki jawabanmu dengan kata-katamu sendiri.
