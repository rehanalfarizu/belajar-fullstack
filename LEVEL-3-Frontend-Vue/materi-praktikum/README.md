# Materi Praktikum — Vue 3

## Cara Belajar

Untuk setiap modul:

1. Baca bab terkait di `materi-teori/README.md`.
2. Baca brief di `soal/README.md`.
3. Ketik ulang file dari `code/`; jangan copy-paste solusi.
4. Jalankan dan cek DevTools console/network.
5. Buat minimal satu failure case.
6. Setelah selesai, bandingkan dengan `contoh/`.
7. Refactor berdasarkan alasan, bukan hanya agar tampak berbeda.

## Urutan

| Modul | Topik | Output |
|---|---|---|
| 01 | Setup dan component | Counter |
| 02 | Directive | Product filter |
| 03 | Props dan slot | Product card |
| 04 | Emit | Add-to-cart event |
| 05 | Reactivity | Cart total |
| 06 | Lifecycle | Fetch dengan cleanup |
| 07 | Composable | Reusable counter |
| 08 | Router | Protected view |
| 09 | Pinia | Cart store |
| 10 | HTTP | Product page |

Semua starter code sengaja memiliki TODO, tetapi tetap harus valid secara
sintaks. Solusi adalah salah satu implementasi, bukan satu-satunya jawaban.
