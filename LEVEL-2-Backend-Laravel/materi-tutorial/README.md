# Materi Tutorial Laravel

Tutorial kanonis berada di [folder tutorial](../tutorial/README.md).

Gunakan folder ini sebagai catatan eksperimenmu:

- Diagram request lifecycle.
- Catatan command Artisan yang sudah dipahami.
- Hipotesis sebelum debugging.
- Hasil query profiling.
- Postmortem singkat setiap bug.

Jangan hanya mencatat “command yang berhasil”. Catat juga alasan, input,
output, dan mengapa pendekatan sebelumnya gagal.
