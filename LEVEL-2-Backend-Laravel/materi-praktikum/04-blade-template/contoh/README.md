# Contoh — Blade Template

Ini solusi referensi. Jangan dibuka sebelum punya jawaban sendiri yang jalan.

Solusi di sini bukan satu-satunya jawaban benar. Kalau Syarat di soal
terpenuhi, test kamu hijau, dan payload XSS tidak jalan, jawabanmu sah.

## Daftar File

| File | Untuk soal | Lokasi di `toko-latihan/` |
|---|---|---|
| `01-products.blade.php` | Soal 01 — Product List | `resources/views/products/index.blade.php` |
| `02-product-card.blade.php` | Soal 02 — Komponen | `resources/views/components/product-card.blade.php` |
| `02-layouts-app.blade.php` | Soal 02 — Layout | `resources/views/layouts/app.blade.php` (+ contoh pemakaian komponen di komentar) |
| `03-detail-produk-aman.blade.php` | Soal 03 — XSS dan Escape | `resources/views/products/show.blade.php` (+ contoh test di komentar) |

## Cara Membandingkan

1. Jalankan test dan payload XSS ke jawabanmu dulu, catat hasilnya.
2. Baca solusi, cari **satu** hal yang berbeda dari jawabanmu.
3. Tanya ke diri sendiri: "Lubang mana yang dia tambal dan aku lewatkan?"
4. Tutup file solusi, perbaiki jawabanmu dengan kata-katamu sendiri.
