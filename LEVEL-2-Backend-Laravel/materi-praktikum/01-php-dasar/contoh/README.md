## Cara Membandingkan

1. Jalankan solusimu dan solusi referensi. Output harus sama.
2. Cari satu hal yang beda cara penulisannya. Tulis di catatan: mana yang lebih mudah dibaca, dan kenapa.
3. Jangan copy-paste solusi ke file latihanmu. Tutup file ini, lalu perbaiki kodemu dari ingatan.
