# Git & GitHub

Fondasi untuk kolaborasi software engineering.

---

## Struktur

```
materi-git-github/
├── materi-teori/
│   └── README.md          → Konsep Git & GitHub
├── materi-praktikum/
│   ├── 01-git-dasar/          → init, add, commit, push
│   ├── 02-git-branching/      → branch, merge, checkout
│   └── 03-github-collaboration/ → fork, PR, code review
├── tutorial/
│   └── README.md          → Panduan langkah demi langkah
└── software/
    └── README.md          → Software yang perlu diinstall
```

---

## Tahapan Belajar

```
1. install software       → materi-git-github/software/
2. baca teori             → materi-git-github/materi-teori/
3. ikut tutorial          → materi-git-github/tutorial/
4. praktik                 → materi-git-github/materi-praktikum/
```

## Tujuan Akhir

Setelah selesai, kamu akan bisa:
- Menggunakan Git untuk melacak perubahan kode
- Bekerja dengan branch di tim
- Mengirim Pull Request ke repository manapun
- Memahami workflow kolaborasi profesional
