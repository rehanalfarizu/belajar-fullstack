## Checklist Kemampuan Git & GitHub

Empat belas kemampuan yang harus sudah dikuasai:

1. Setup Git config (`user.name`, `user.email`).
2. Buat repository baru dengan `git init`.
3. Cek status dengan `git status`.
4. Stage file dengan `git add`.
5. Commit dengan `git commit`.
6. Lihat history dengan `git log`.
7. Buat branch baru dengan `git branch`.
8. Pindah branch dengan `git checkout` atau `git switch`.
9. Gabung branch dengan `git merge`.
10. Push ke GitHub dengan `git push`.
11. Clone repository dengan `git clone`.
12. Fork repository orang lain.
13. Buat Pull Request di GitHub.
14. Resolve merge conflicts.

---

## Tips

Enam tips untuk belajar Git lebih efektif:

1. Selalu jalankan `git status` sebelum dan sesudah `git add`.
2. Gunakan `git log --oneline` untuk history yang lebih rapi.
3. Gunakan `git diff` untuk melihat perubahan sebelum commit.
4. Tulis commit message yang jelas: `feat: ...` atau `fix: ...`.
5. Branch di komputer lokal, push ke GitHub untuk backup.
6. Selalu `git pull` sebelum mulai kerja.
