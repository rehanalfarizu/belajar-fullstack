# Software — LEVEL 0: Git & GitHub

Folder ini berisi panduan install dan setup **software yang dibutuhkan** untuk belajar Git dan GitHub.

---

## Daftar Software

Empat software dasar yang perlu disiapkan:

1. `01-git-install.md` — Git, version control system.
2. `02-github-account.md` — GitHub Account, platform untuk menyimpan repo.
3. `03-vscode-install.md` — VS Code, text editor untuk menulis kode.
4. `04-terminal-basics.md` — Terminal, command line interface.

---

## Cara Pakai

Empat langkah untuk menyiapkan environment:

1. Install software sesuai urutan dari atas ke bawah.
2. Cek versi setelah install untuk memastikan berhasil.
3. Buat akun GitHub jika belum punya.
4. Ikuti instruksi di setiap file dengan teliti.

---

## Urutan Install yang Disarankan

Empat langkah berurutan:

1. **STEP 1** — Install Git (wajib untuk semua level).
2. **STEP 2** — Buat akun GitHub (wajib untuk semua level).
3. **STEP 3** — Install VS Code (text editor).
4. **STEP 4** — Pelajari dasar-dasar Terminal.

---

## Verifikasi Install

Tiga command untuk memastikan semua software terinstall dengan benar:

```bash
# Cek Git
git --version
# Output harus seperti: git version 2.40.0

# Cek GitHub CLI
gh --version
# Output harus seperti: gh version 2.31.0

# Cek VS Code
code --version
```

---

## Checklist Sebelum Lanjut ke Level 1

Lima poin yang harus sudah tercapai:

1. Git terinstall dan `git --version` berhasil.
2. Akun GitHub sudah dibuat dan diverifikasi.
3. VS Code terinstall.
4. Bisa membuka terminal atau command prompt.
5. Sudah mencoba tiga perintah dasar: `pwd`, `ls`, dan `cd`.
