# Materi Praktikum 02 — Git Branching

## Tujuan Pembelajaran

Setelah menyelesaikan modul ini, kamu akan mampu:
- Membuat branch baru
- Beralih antar branch
- Menggabungkan branch (merge)
- Menghapus branch
- Memahami workflow branching untuk kolaborasi tim

---

## Alur Kerja

```
1. Baca → soal/02-git-branching.md
2. Praktik → ketik perintah di terminal
3. Verify → git branch, git log --oneline --graph --all
4. Experimen → buat branch lain, merge, hapus
```

---

## Konsep Branching

```
main ────────────────────────────────────
    └── feature/login ─── merge ──► main
```

Branch = workspace terpisah yang tidak mengganggu `main`.
