# Materi Praktikum 03 — GitHub Collaboration

## Tujuan Pembelajaran

Setelah menyelesaikan modul ini, kamu akan mampu:
- Melakukan Fork& Clone repository orang lain
- Membuat dan menggabungkan Pull Request
- Memahami Code Review di GitHub
- Berkolaborasi dengan tim di repository yang sama

---

## Alur Kerja

```
1. Baca → soal/01-github-collaboration.md
2. Praktik → ketik perintah di terminal
3. Verify → cek Pull Request di GitHub
4. Experimen → fork repo lain, buat PR
```

---

## Konsep Kolaborasi di GitHub

```
Repository Original (Owner)
        │
        │ fork
        ▼
Repository Fork (di akun kita)
        │
        │ clone
        ▼
Lokal Komputer Kita
        │
        │ push
        ▼
Branch di Repository Fork (di akun kita)
        │
        │ Pull Request
        ▼
Repository Original → Code Review → Merge
```
