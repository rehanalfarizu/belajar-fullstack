## Tips Belajar

Lima tips untuk memaksimalkan LEVEL-0:

1. **Jangan copy-paste commands — KETIK sendiri**. Melatih muscle memory.
2. **Setelah install software, VERIFIKASI langsung**. Buka terminal, ketik command verifikasi. Jangan skip langkah ini.
3. **BUAT ALIASES di `~/.zshrc`**. Setup sekali, hemat waktu setiap hari.
4. **EKSPERIMEN dengan command**. Jangan takut break sesuatu — yang di-break tinggal buat ulang.
5. **Tutup browser, buka Terminal**. Developer menghabiskan sebagian besar waktu di terminal.
