# Materi Tutorial — LEVEL 0

Folder ini berisi **panduan langkah demi langkah** untuk membuat 1 project nyata dari awal. Berbeda dengan materi-teori yang fokus ke penjelasan konsep, tutorial di sini fokus ke **praktik langsung** — kamu akan membangun sesuatu yang bisa langsung digunakan.

---

## Isi Folder

- **02-dev-environment-tutorial.md** — Tutorial setup workstation lengkap: install Git, configure, generate SSH key, dan connect ke GitHub. Panduan ini adalah langkah pertama yang **harus kamu kerjakan** sebelum mulai coding.

---

## Cara Pakai

1. **BACA** `02-dev-environment-tutorial.md` dari awal sampai akhir
2. **IKUTI** setiap langkah dengan mengetik perintah di terminal
3. **JANGAN SKIP** langkah apa pun — semuanya penting
4. **VERIFIKASI** setiap langkah dengan command yang tersedia
5. **LANJUT** ke materi-teori setelah environment siap

---

## Alur Belajar yang Disarankan

```
STEP 1 → Ikuti tutorial setup environment
         (02-dev-environment-tutorial.md)

STEP 2 → Verifikasi semua software terinstall dengan benar
         (cek checklist di bawah)

STEP 3 → Lanjut ke materi-teori
         - 01-command-line-fundamental.md
         - 03-vscode-text-editor.md
         - 02-git-github-fundamental.md

STEP 4 → Praktikkan dengan latihan
         (materi-praktikum/01-latihan-command-line/)

STEP 5 → Bangun portfolio pertama
         → hasilnya push ke GitHub
```

---

## Target Setelah Menyelesaikan Tutorial Ini

```
□ Git terinstall dan terkonfigurasi
□ VSCode terinstall dengan extensions penting
□ Node.js dan npm terinstall
□ SSH key sudah tersambung ke GitHub
□ Punya repository GitHub pertamamu
□ Sudah bisa push kode ke remote repository
```

---

## Tips

```
1. Ketik perintah, jangan copy-paste — supaya kamu ingat
2. Kalau error, baca pesan errornya dulu sebelum googling
3. Buat alias untuk command yang sering dipakai
4. Dokumentasikan sendiri langkah-langkahnya di notes
```
