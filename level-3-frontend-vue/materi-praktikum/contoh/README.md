# Contoh Solusi — Track Vue

> **Ini solusi referensi. Jangan dibuka sebelum punya jawaban sendiri yang jalan.**

Kenapa? Kalau kamu lihat jawaban duluan, otakmu cuma "mengenali" kode, bukan
"menyusun" kode. Rasanya paham, padahal belum. Di tes kerja atau saat ngoding
sendiri, yang dipakai itu kemampuan menyusun.

## Cara Pakai Folder Ini

1. Kerjakan soal di `../soal/` sampai **jalan** dan semua checkbox Verifikasi
   sudah kamu centang.
2. Baru buka file contoh dengan nomor yang sama.
3. Bandingkan, jangan salin. Tanya ke diri sendiri:
   - Bedanya di mana?
   - Edge case apa yang contoh tangani tapi punyaku belum?
   - Ada yang punyaku lebih jelas? (Bisa jadi! Contoh bukan satu-satunya jawaban.)
4. Kalau mau memperbaiki kodemu, **tutup file contoh dulu**, lalu ketik ulang
   dari ingatan dan alasanmu sendiri.
