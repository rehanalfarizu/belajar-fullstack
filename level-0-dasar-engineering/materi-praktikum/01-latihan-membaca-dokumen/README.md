# Latihan Membaca Dokumen: ERD, PRD, dan API

Teori: [Membaca Dokumen Teknis](../../materi-teori/05-membaca-dokumen-teknis.md).

Latihan ini memakai **satu studi kasus** yang sama dari tiga sudut: sistem
pemesanan jasa pembuatan website. Tujuannya melatih kebiasaan kerja nyata: baca
requirement, temukan yang belum jelas, lalu ubah menjadi data, endpoint, dan test.

## Isi folder

```text
studi-kasus/
  01-prd-pemesanan.md     requirement produk (sengaja ada bagian yang ambigu)
  02-erd-pemesanan.md     rancangan database
  03-api-pemesanan.md     kontrak API
soal/
  01-membaca-erd.md       Minggu 10
  02-membaca-prd-dan-api.md  Minggu 15
  03-fitur-baru-kode-promo.md Minggu 15
contoh/                   jawaban referensi, buka hanya setelah selesai menjawab
```

## Urutan

| Kapan | Kerjakan |
|---|---|
| Minggu 10 | baca teori bagian ERD, lalu [Soal 01](soal/01-membaca-erd.md) |
| Minggu 15 | baca teori bagian PRD dan API, lalu [Soal 02](soal/02-membaca-prd-dan-api.md) dan [Soal 03](soal/03-fitur-baru-kode-promo.md) |

## Aturan

- Tulis jawaban di `latihan-saya/membaca-dokumen/`, lalu commit.
- Query SQL harus benar-benar dijalankan di PostgreSQL, bukan hanya ditulis.
- Buka `contoh/` setelah semua nomor terjawab. Bandingkan alasannya, bukan
  kecocokan kata per kata. Jawabanmu boleh berbeda selama alasannya kuat.
