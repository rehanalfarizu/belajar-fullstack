# Latihan Kode Rapi

Teori: [Kode yang Rapi dan Folder yang Teratur](../../materi-teori/06-kode-rapi-dan-struktur-folder.md).

```text
code/01-kasir-spaghetti.js     program yang benar tapi berantakan
soal/01-refactor-kasir.md      langkah merapikannya (Minggu 7)
contoh/01-kasir-rapi.js        salah satu hasil refactor + test
contoh/01-kasir-rapi.test.js   jalankan dengan: node --test
```

Buka `contoh/` hanya setelah versi rapimu sendiri lolos `diff`.
